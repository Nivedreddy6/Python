# Python Practice & Projects 🐍

A comprehensive collection of Python scripts, daily practice exercises, and object-oriented programming (OOP) projects.

---

## 📂 Repository Structure

### 🚀 Projects
- **[ATM__Project.py](ATM__Project.py)**: An interactive ATM simulator built with Object-Oriented Programming (OOP). Features include PIN validation, balance inquiry, deposit, withdrawal, PIN change, fast cash, and transaction history tracking.
- **[student_management_project.py](student_management_project.py)**: A university management system demonstrating multiple inheritance, class design, and object attributes for faculty and students.

### 📅 Daily Practice & Topic Exercises
A structured series of Python exercises covering core concepts from basics to advanced topics:
- **`day1.py` - `day12.py`**: Python syntax, variables, data types, conditional statements, loops, lists, dictionaries, tuples, sets, and functions.
- **`day_23.py` - `day_30.py`**: Advanced topics including OOP principles, inheritance, polymorphism, encapsulation, file operations, and practical problem-solving.

---

## 🛠️ Requirements & Setup

1. **Python**: Ensure you have Python 3.8+ installed.
2. **Clone the repository**:
   ```bash
   git clone https://github.com/Nivedreddy6/Python.git
   cd Python
   ```
3. **Run any script**:
   ```bash
   # Run ATM Simulation
   python ATM__Project.py

   # Run Student Management System
   python student_management_project.py

   # Run Daily Practice
   python day1.py
   ```
